# Account and purchases

## Store status

The catalog has no products yet and purchases are disabled. This guide describes the process that will be available when the first resource is released.

## Cfx.re account

Check which account should receive the resource and which account owns your server before purchasing. Authorization is handled through Tebex and Cfx.re. E4Studios will not ask for those services’ passwords.

## Payment and delivery

1. Read the requirements and deliverables on the product page.
2. Link the receiving account.
3. Check the amount, currency and taxes in Tebex checkout.
4. Keep the receipt and transaction reference.
5. Check asset access in [Cfx.re Portal](https://portal.cfx.re/) when that is the stated delivery method.

## Missing resource

Check the account used and the payment status. If payment is confirmed but access is missing, contact support with the transaction reference. Do not start by making another payment.

Payment issues can also be raised with [Tebex support](https://www.tebex.io/contact/checkout).
