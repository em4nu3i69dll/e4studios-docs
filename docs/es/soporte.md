# Soporte

Puedes escribir a [contacto@em4nu3l69dll.dev](mailto:contacto@em4nu3l69dll.dev) o entrar al [Discord de E4Studios](https://discord.gg/NHmBGxvwp9).

## Qué enviar

- Nombre y versión del recurso.
- Framework y dependencias relevantes.
- Qué esperabas que ocurriera y qué ocurrió.
- Pasos para reproducir el problema.
- Mensaje de error completo y capturas útiles.
- Referencia de la transacción de Tebex si la consulta corresponde a una compra.

## Qué ocultar

Revisa los registros antes de enviarlos. No compartas contraseñas, tokens, claves de licencia, credenciales de base de datos ni información personal de jugadores. No publiques el archivo `server.cfg` completo.

No solicitamos acceso remoto ni contraseñas como requisito inicial para revisar una consulta.

## Alcance

El soporte se refiere al funcionamiento documentado de los recursos. La ficha de cada producto informa sus condiciones específicas. Los desarrollos a medida y las integraciones externas deben acordarse por separado.
