# Problemas frecuentes

## You lack the required entitlement

El servidor no tiene el permiso de uso requerido para un asset protegido. Comprueba la cuenta propietaria del servidor y la cuenta que recibió el recurso. Consulta la [explicación de Cfx.re](https://docs.fivem.net/docs/server-manual/asset-escrow/).

## Falta una dependencia

Comprueba que el recurso requerido esté instalado, que su carpeta conserve el nombre correcto y que arranque antes del recurso que depende de él. Revisa el primer error de la consola, no solo los mensajes que aparecen después.

## La interfaz no se abre

Revisa los errores del cliente y de la consola del servidor. Comprueba el comando o la tecla documentados y las condiciones necesarias para abrir la interfaz. Aísla posibles conflictos en un entorno de prueba.

## Error de base de datos

Conserva el mensaje completo. Comprueba la conexión y las migraciones indicadas en la guía del recurso. No borres tablas ni ejecutes SQL de otro producto para intentar corregirlo.

## La compra no aparece

Revisa [cuenta y compras](./cuenta.md). Necesitarás la cuenta utilizada y la referencia de Tebex para solicitar ayuda.

## El problema continúa

Prepara los pasos para reproducirlo y consulta [cómo contactar con soporte](./soporte.md).
