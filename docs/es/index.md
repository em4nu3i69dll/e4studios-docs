# Introducción

Guías de cuenta, instalación y soporte para los recursos de E4Studios.

## Antes de empezar

Para instalar un recurso necesitas acceso a los archivos y a la consola de tu servidor FiveM. La ficha de cada producto indicará los frameworks, las versiones y las dependencias compatibles.

Actualmente no hay scripts publicados en la tienda. Las instrucciones específicas de cada recurso se incorporarán con su lanzamiento.

- [Cuenta y compras](./cuenta.md) explica cómo recibir un recurso.
- [Instalación](./instalacion.md) reúne los pasos generales de preparación y arranque.
- [Actualizaciones](./actualizaciones.md) explica cómo respaldar y comprobar una versión nueva.
- [Problemas frecuentes](./problemas.md) ayuda a revisar errores comunes.
- [Soporte](./soporte.md) indica qué información enviar para resolver una incidencia.
