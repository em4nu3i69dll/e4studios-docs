# Atualizações

## Antes de atualizar

Leia as notas da versão e confira mudanças de dependências, configuração ou base de dados. Não presuma que todas as versões podem ser instaladas substituindo a pasta inteira.

## Backup

Guarde a versão instalada, sua configuração e uma cópia da base de dados. Preserve os arquivos necessários para voltar à versão anterior se o teste falhar.

## Aplicar a versão

1. Teste o pacote fora de produção.
2. Compare a configuração com a versão instalada.
3. Siga as migrações documentadas, quando houver.
4. Inicie as dependências e o recurso na ordem indicada.
5. Confira o console e as funções principais.

## Se ocorrer um problema

Interrompa o teste e guarde o erro completo. Para voltar à versão anterior, restaure os arquivos e os dados alterados a partir do backup. Não misture versões sem verificar a compatibilidade.

Cada página de produto informa quais atualizações estão incluídas.
