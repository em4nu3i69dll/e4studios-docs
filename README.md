# E4Studios Docs

Documentación de E4Studios en español, inglés y portugués.

[Abrir documentación](https://em4nu3i69dll.github.io/e4studios-docs/es/) · [Tienda](https://e4studios.xyz/es/) · [Discord](https://discord.gg/NHmBGxvwp9)

El dominio previsto es `docs.e4studios.xyz`. Su conexión DNS está pendiente.

## Editar una página

Las páginas están en `docs/es`, `docs/en` y `docs/pt`. Se pueden editar desde GitHub con el botón de lápiz o desde el enlace al pie de cada guía.

Los cambios en `main` pasan por la compilación de GitHub Actions. La versión aprobada se publica en GitHub Pages.

## Desarrollo

```sh
npm ci
npm run dev
```

## Compilar

```sh
npm run build
```

La salida está en `docs/.vitepress/dist`.

## Contenido

Estas guías cubren cuenta, instalación, actualizaciones y soporte. Las instrucciones específicas se incorporarán con cada recurso publicado.
